## 1. OpenCorpora (pymorphy2/pymorphy3) — РЕКОМЕНДАЦИЯ

### Получение (реально скачано)

Прямой экспорт `opencorpora.org` (`dict.opcorpora.txt.bz2`) на момент исследования
**недоступен** — сервер отдаёт `error code 522` (Cloudflare, origin down) и по HTTP,
и по HTTPS. Проверено дважды.

Рабочий путь — **готовый скомпилированный словарь OpenCorpora из пакета
`pymorphy2-dicts-ru`** (это тот же самый словарь OpenCorpora, ревизия 417127,
`source_version 0.92`, `source: opencorpora.org` — подтверждено в `meta.json` пакета):

```bash
pip3 install pymorphy2-dicts-ru            # или pymorphy3-dicts-ru
# extractor (нужен dawg_python — ставится с pymorphy2):
python3 - <<'PY'
import pymorphy2_dicts_ru
from pymorphy2.opencorpora_dict.storage import load_dict
d = load_dict(pymorphy2_dicts_ru.get_path())
with open("opcorpora_forms.txt","w",encoding="utf-8") as f:
    for key in d.words.iterkeys():   # ключи DAWG = словоформы
        f.write(key+"\n")
PY
```

- Сырых ключей словоформ в DAWG: **5 140 055**.
- После нормализации (33 буквы, lowercase, дедуп, ≤40): **N = 3 022 245**.
- (Формы уже хранятся в нижнем регистре; отсев — записи с дефисом/латиницей/цифрами
  и коллапс дублей.)

Альтернатива, если origin поднимется: `dict.opcorpora.txt.bz2` /
`dict.opcorpora.xml.bz2` с `http://opencorpora.org/files/export/dict/` — тот же
словник, парсится тривиально (`<f t="...">` = словоформы).

### Лицензия (дословно и по существу)

- **Пакет-обёртка** `pymorphy2-dicts-ru`: `License: MIT license` (из METADATA
  пакета). **Но MIT покрывает только скрипты сборки/упаковки, НЕ сами данные.**
  README `kmike/pymorphy2-dicts` прямо говорит: *«For Russian it downloads data from
  http://opencorpora.org»* — данные приходят из OpenCorpora.
- **Данные OpenCorpora**: распространяются под **Creative Commons
  Attribution-ShareAlike (CC-BY-SA)** — общепринятая и повсеместно цитируемая при
  редистрибуции этого датасета лицензия словаря OpenCorpora. (Движок аннотирования
  `OpenCorpora/opencorpora` на GitHub — отдельно, GPL-2.0; к словарю не относится.)
  Точную версию (3.0) на самом сайте подтвердить в момент исследования не удалось из-за
  недоступности origin (522), но лицензия семейства CC-BY-SA — факт, зафиксированный в
  документации pymorphy2 и многочисленных редистрибуциях.

### Вердикт по App Store

**Совместимо.** CC-BY-SA — это copyleft для **данных**, а не для кода:

1. **Атрибуция** — обязательна: указать OpenCorpora + ссылку + лицензию на экране
   «О программе»/лицензии (как уже сделано для Лебедева в `docs/LICENSE-dict.md`).
2. **ShareAlike** — производный словарь (`ru_dict.bin`, раскрытый/перепакованный из
   OpenCorpora) считается адаптацией БАЗЫ ДАННЫХ и должен распространяться под той же
   **CC-BY-SA**. На практике: приложить лицензию словаря к артефакту и указать, что
   производный словарь доступен под CC-BY-SA (можно опубликовать генератор/дамп форм).
3. **Код приложения НЕ заражается** — ShareAlike распространяется на саму базу
   словоформ, а не на закрытый исходник iOS-приложения, которое лишь её *использует*.
   Бинарный формат ANGR — это упаковка данных, а не производное ПО от лицензии словаря.

Итог: проприетарное платное App Store-приложение может встраивать этот словарь при
условии (а) видимой атрибуции OpenCorpora/CC-BY-SA и (б) готовности отдать сам
производный словарь под CC-BY-SA. Это единственное реальное обязательство сверх
текущего Лебедева.

### Качество (реально проверено)

- Покрытие пробника (18 частотных/краевых слов, включая `ёлка`, `ёж`, `подъезд`,
  `встретившимся`, `абракадабра`): **100%**.
- Случайная выборка — все реальные словоформы: `неверхоглядское`,
  `дифференциальные`, `псевдонародного`, `бомбомётным`, `израсходованными` и т.п.
- `ё` присутствует и сохранён: **124 668** форм содержат `ё`.
- Мусора практически нет — это выверенный лингвистический словарь, а не токены текста.

## 2. danakt/russian-words — лучший пермиссивный (MIT) кандидат

### Получение (реально скачано)

```
https://raw.githubusercontent.com/danakt/russian-words/master/russian.txt
```

Кодировка **windows-1251**, одно слово на строку, «все морфологические формы».
Файл 18 МБ, скачался успешно.

```bash
iconv -f CP1251 -t UTF-8 russian.txt | <normalize>
```

- Заявлено в README: 1 531 464 записи (+ отдельный файл `russian_surnames.txt` на
  877 227 фамилий, не учитывался).
- После нормализации: **N = 1 525 424**.

### Лицензия (дословно)

```
MIT License
Copyright (c) 2020 Danakt Frost
Permission is hereby granted, free of charge, ... to deal in the Software without
restriction, including ... use, copy, modify, merge, publish, distribute,
sublicense, and/or sell copies ... [стандартный MIT]
```

### Вердикт по App Store

**Полностью совместимо, самая простая лицензия.** MIT: только сохранить копирайт-нотис
Danakt Frost в списке лицензий. **Никакого ShareAlike, код и словарь свободны.**
(Оговорка происхождения: данные, вероятно, восходят к hunspell/AOT-раскрытию, но сам

это означает потерю различения `ё`, но все слова валидны. Из 1.52M форм **206 539**
отсутствуют в OpenCorpora — реальное дополнение (иная нормализация `ё` + иной словник).

## 3. hermitdave FrequencyWords ru — НЕ рекомендуется

### Получение (реально скачано)

```
https://raw.githubusercontent.com/hermitdave/FrequencyWords/master/content/2018/ru/ru_full.txt
```

Формат `слово частота` на строке, UTF-8, 29 МБ, скачался успешно.

- После нормализации (первое поле): **N = 1 050 620**.

### Лицензия

Репозиторий FrequencyWords — **MIT**; но исходный корпус — частотные списки из
**OpenSubtitles** (субтитры), у которых собственные условия (CC-BY-SA у OPUS/
OpenSubtitles-датасета). Для игры это второстепенно из-за качества.

### Качество — ПЛОХОЕ

Это не словарь, а токены из субтитров. Из форм, которых нет в OpenCorpora
(563 044 «дополнительных»), выборка — сплошной мусор для словесной игры:
транслит имён (`дэррилу`, `зиннеман`, `флигман`), опечатки (`останаливает`,
`апубликуете`, `конкретн`), OCR-хлам (`нейоуяафомтаи`, `саудтрэк`). **Добавлять нельзя** —
испортит анаграммы ложными «словами». Не использовать.

## 4. AOT / Zaliznyak (aot.ru, seman) — LGPL, но не раскрывается через unmunch

### Доступность и получение

- Исходный морфословарь AOT: `github.com/sokirko74/aot` и `github.com/sokirko74/morph_dict`
  (ранее `sourceforge.net/projects/seman`). Прямые «magic» URL на `aot.ru/download/…`
  дают 404; страница `download.php` отдаёт 200, но без прямых ссылок (JS).
- Практически доступная форма — **hunspell-конверсия AOT** (Yakov, «Russian spellcheck
  dict, based on works of AOT»), скачана как `.oxt` (zip) с LibreOffice Extensions:
  `dict-ru-ru-aot-0-2-2.oxt` (1.28 МБ). Внутри `russian-aot.dic` (379 222 основы,
  CP1251) + `russian-aot.aff`.

### Лицензия (дословно по существу)

- Ядро AOT/seman: *«distributed under the Library GNU Public Licence»* (**LGPL**).
- Hunspell-конверсия (Yakov): **LGPL v2.1** (заявлено в описаниях расширений
  LibreOffice/Firefox/OpenOffice).

### Вердикт по App Store

Лицензия **LGPL v2.1 — App-Store-совместима для данных** (пермиссивнее CC-BY-SA в
части ShareAlike на *приложение*; словарь как «библиотека данных», атрибуция +
доступность модификаций словаря). Но —

### Качество — НЕПРИГОДНО через unmunch

`unmunch russian-aot.dic russian-aot.aff` **некорректно раскрывает** этот словарь:
`.aff` без строки `SET`, сложные флаги → комбинаторный взрыв. Реально `unmunch` выдал
**332 млн строк** и переполнил диск. Даже с обрезкой входа до 60M строк «уникальных
форм» получилось 17.8M, но выборка — **сплошная кириллическая абракадабра**
(`плпмпбъеммбби`, `ртедбдпмбйдбпн`), доля мусора по эвристике 5+ согласных = **55%+**.
Это артефакт мис-раскрытия (кодировка + аффиксы), а не реальные слова.

Вывод: сам словарь AOT качественный и используется в реальных спелчекерах, но
**корректно раскрыть его в плоский список словоформ через `unmunch` нельзя** — нужен
родной тулкит AOT (сборка `sokirko74/aot`), что выходит за рамки задачи и не даёт
выигрыша над OpenCorpora. **Не брать этим путём.**

> ⚠️ Практическая заметка для генератора: `unmunch` на «плохих» `.aff` (как у AOT)
> может произвести десятки ГБ и переполнить диск. Любой новый hunspell-источник
> раскрывать **потоково с жёстким лимитом строк** (`| head -n N |`) и проверять
> выборку на мусор ПЕРЕД записью артефакта.

## Как внедрить рекомендацию в `scripts/gen_anagram_dict.py`

Заменить блок `ensure_source_dict` + `unmunch_words` на извлечение форм из
OpenCorpora-словаря pymorphy2. Остальной пайплайн (нормализация, упаковка ANGR v1,
round-trip, отчёт) — без изменений; `normalize_words` уже совпадает с методом подсчёта.

Псевдо-diff источника (концептуально, генератор в этой задаче НЕ меняется):

```python
# Вместо AFF/DIC + unmunch:
#   1. Гарантировать словарь: pip install pymorphy2-dicts-ru (кэш-путь),
#      либо скачать dict.opcorpora.txt.bz2 когда origin доступен.
#   2. raw_lines = список ключей DAWG (см. extractor выше) —
#      d = load_dict(pymorphy2_dicts_ru.get_path()); d.words.iterkeys()
#   3. Дальше как есть: normalize_words(raw_lines) -> ~3 022 245 форм.
```

Для **максимума ~3.23M** — дополнительно скачать danakt (`iconv CP1251→UTF-8`),
слить множества перед упаковкой: `words = opc_set | danakt_set`. Лицензионно итог
остаётся под CC-BY-SA (из-за OpenCorpora), danakt-часть под MIT.

### Обязательства по лицензии для App Store (итог)

- **Атрибуция OpenCorpora + CC-BY-SA** на экране лицензий (по образцу существующего
  `docs/LICENSE-dict.md` для Лебедева). Если добавляется danakt — плюс MIT-нотис
  «Copyright (c) 2020 Danakt Frost».
- **ShareAlike**: производный словарь (`ru_dict.bin`) — под CC-BY-SA; сделать доступным

## Приложение: методология измерения

Нормализация идентична `scripts/gen_anagram_dict.py`:

```python
ALPHABET = "абвгдеёжзийклмнопрстуфхцчшщъыьэюя"   # 33 буквы
seen = set()
for line in source:
    w = line.strip().lower()
    if not w or len(w) > 40: continue
    if all(ch in ALPHABET for ch in w): seen.add(w)
N = len(seen)
```

Все N в этом документе — вывод `len(seen)` на реально скачанных файлах (2026-07-08).
Текущий эталон Лебедева, пересчитанный тем же кодом: **1 254 910** (совпадает с
`docs/anagramizer-dict-report.md`), что подтверждает корректность методики.
